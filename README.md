# Hangman Game in Python 🐍

A classic text-based Hangman game built in Python as part of CodeAlpha internship tasks. 

## Features
* Random word selection from a curated word list.
* Input validation for single alphabet characters and duplicate guesses.
* Dynamic tracking of incorrect guesses and remaining lives.

## How to Run
1. Ensure you have Python installed (Python 3.x recommended).
2. Clone or download this repository.
3. Open your terminal in the project directory and run:
   ```bash
   python hangman_game.py
